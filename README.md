# SCS Mod Manager

Offline viewer and cleaner for ETS2 / ATS mods. A single HTML file, no install and no internet needed.

## Use
1. Open `ets2_mod_manager.html` in Chrome or Edge.
2. Click **Open mod folder…** and pick `Documents\Euro Truck Simulator 2\mod` (or the ATS one).
3. Each mod shows its thumbnail, name, file name, version, author, description and compatible game versions.
4. Mark mods as **Keep** or **Delete** (deleted ones turn red), then press **Delete marked mods**.

By default marked mods are moved to a `_removed_mods` folder inside the mod folder so you can restore them. Untick the box to delete permanently.

## Limits
- Only the chosen folder is scanned (no subfolders / Workshop folders).
- Mods in the game's native archive format show only the file name.
- TGA/DDS thumbnails can't be displayed.
